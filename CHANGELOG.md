# Changelog - BASIC OUTDOOR

All notable changes to BASIC OUTDOOR watch face will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

---

## [2026_11_24]

### Added
- 21 famous peak sketch backgrounds, traced from real photos: Mont Blanc, K2, Everest, Balaïtous, Vignemale, Gabizos, Pic du Midi d'Ossau, Cirque de Gavarnie, Pic du Midi de Bigorre, Matterhorn, Tre Cime di Lavaredo, Mount Fuji, Ama Dablam, Fitz Roy, Torres del Paine, Half Dome, Denali, Aconcagua, Kilimanjaro, Uluru, Aoraki / Mount Cook (29 backgrounds in total)
- fēnix 9 series support: fēnix 9 43mm / 47mm, fēnix 9 Pro 43mm / 47mm / 51mm, fēnix 9 Pro Solar 47mm / 51mm

### Fixed
- Total distance (30 days / month / week, bike, run, swim) showing 0 on some watches (e.g. Enduro 3) whose activity history uses Garmin time

---

## [2026_11_22]

### Added
- Initial release of BASIC OUTDOOR
- Large centered time with fixed-position seconds and AM/PM
- Top zone sketch background: Mountains (default), Trail Runner, Cyclist, Hiker, Lake, Runner / Cyclist / Swimmer silhouettes, or None
- Configurable sketch color
- 6 data cells (title, colored icon, value) around a segmented center goal gauge
- Bottom center field (heart rate by default)
- Top text field (date by default)
- 4 info fields: Info Top (moon), Info Left, Battery, Info Right
- Configurable backgrounds for top zone, cells and bottom zone
- 1 px zone separator lines with configurable color
- 31 customizable colors, including each field icon color
- 3 custom hexadecimal colors
- Dual weather support (Garmin Weather + OpenWeatherMap)
- 7 date display formats
- Multilingual support (19 languages)
- Intelligent power saving (screen saver + screen off)
- Screen saver: time and date below the sketch (centered without sketch), battery icon and level at the bottom, dedicated Screen Saver Color
- Show / hide titles, icons and units of the 6 side fields (units hidden by default, remaining elements re-centered, same value font in all fields, weather condition icon always shown)
- Ticks around top and bottom zones only, data cells up to the screen edge, bigger fonts
- Inverted arc below the gauge for a bigger bottom center field
